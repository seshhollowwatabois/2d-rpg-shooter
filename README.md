# Shadowlands: Outbreak

First playable browser prototype of a top-down 2D RPG shooter.

## Controls
- WASD / Arrow keys — move
- Mouse — aim
- Left click / Space — shoot
- Mobile — virtual joystick + FIRE
- Enter / Space after death — restart

## Features
- Enemy spawning and chasing
- Shooting and collision
- HP, XP and leveling
- Coins and kill counter
- Elite enemies
- Particle effects and screen shake
- Mobile touch controls

## Roadmap
Weapons/reload, inventory, loot, NPCs, quests, shops, multiple maps, bosses, saves and improved art.
